Overview

This page provides a compact entry point for reviewers. The artifact contains ROS 2 teleoperation code, gNB-side KPI recording utilities, KPI parsing and analysis tooling, and a run-level dataset sample for networked teleoperation experiments.

Artifact Contents

Top-Level Guide Artifact purpose, layout, and review entry points. Installation Software and hardware dependencies. Run Examples Software-only and full-system execution paths. Dataset Description Run-level organization, fields, and privacy notes.

Dataset Organization

The sample dataset is stored under networked_teleoperation_dataset/. It is organized by delay condition and pseudonymized user identifier. Each run can contain gNB KPI logs, ROS 2 bag data, metadata, and subjective ratings.

Software Components

code/teleoperation_ros2_pkg/ ROS 2 teleoperation and simulation interface. code/oai_gnb_kpi_recorder/ gNB-side KPI recording utilities and deployment notes. code/ros2_kpi_toolkit/ Parsing, analysis, export, and utility scripts for ROS 2 KPI data.

Software-Only Review Path

Reviewers can inspect package structure, run static checks, examine dataset files, and follow the software-only examples without local radio hardware. Start with RUN_EXAMPLE.md and the per-component README files.

Hardware-Dependent Full System

Full-system execution requires local ROS 2, robot, 5G core, gNB, UE, SDR, and network configuration. Hardware-dependent steps are documented separately and require local parameter substitution before use.

See INSTALL.md and code/oai_gnb_kpi_recorder/README.md.

Figures and Demo Materials

Demo materials are intentionally limited to repository-local files for anonymous review. Place any additional anonymized screenshots, diagrams, or videos under docs/assets/ before enabling public links from this page.
